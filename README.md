# Ride-Sharing Demand Prediction System

Predicts ride demand by zone and time of day, recommends driver repositioning, and shows a live demand heatmap.

## Run
pip install -r requirements.txt
python generate_data.py
python run.py
Open http://127.0.0.1:5000
